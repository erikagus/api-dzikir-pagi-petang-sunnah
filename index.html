API Dzikir Pagi & Petang Sesuai Sunnah

API statis (berkas JSON) berisi dzikir pagi dan petang dari buku Dzikir Pagi & Petang Sesuai Sunnah Nabi, Yayasan Cinta Sedekah. Isi buku diterbitkan tanpa perubahan.

Endpoint

  • api/v1/index.json: daftar endpoint, versi, dan id item
  • api/v1/pagi.json: dzikir pagi
  • api/v1/petang.json: dzikir petang
  • api/v1/all.json: pagi dan petang sekaligus
  • api/v1/meta.json: metadata buku, waktu afdhol dan longgar
  • api/v1/items/<id>.json: satu item, contoh pagi-ayat-kursi

Dokumentasi

  • README (skema dan contoh pemakaian)
  • FLAGS: item yang perlu diverifikasi
  • NOTICE: hak cipta dan atribusi

Pemberitahuan

Isi adalah milik Yayasan Cinta Sedekah (cintasedekah.org) dan tidak dilisensikan ulang. Teks Arab disalin dari kanglerian/api-dzikir-pagi-petang (Lerian). Verifikasi teks Arab sebelum dipakai untuk hal penting.
